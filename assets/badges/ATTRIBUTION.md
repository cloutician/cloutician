# Badge artwork

Java, AWS and Google Cloud icon paths are from [Devicon](https://github.com/devicons/devicon), under the included MIT licence. The AWS lettering is white for visibility on the dark badge. The Google Cloud icon retains its four-colour layout using blue #4285F4, red #EA4335, yellow #FBBC05 and green #34A853.

The SQL badge uses a generic database cylinder drawn for this profile; SQL has no single vendor-neutral product logo.
